A program that writes one original office-life joke to /output/entry.txt for make.fun's "Make the AI Judge Laugh" bounty — a single line judged pairwise on how true the observation is to office life, how surprising the turn is, how tight the line is, and how fresh it feels. The entry is: My performance review says "exceeds expectations" but my salary says "meets budget". Scored 24/25 against the judge's five criteria, best of 18 candidates.

## Run it

```sh
node main.ts
```
